# Carpeta de imágenes de NightClaw AI

Las imágenes de la web deben guardarse aquí.

## Logo principal
- Ruta que utiliza la web: `images/1.png`
- Tamaño recomendado: 512 × 512 píxeles
- Formato: PNG, preferiblemente con fondo transparente

Sube tu logo a esta carpeta con el nombre exacto `1.png`. Si lo subes con otro nombre, tendrás que cambiar la ruta en `index.html`.

## Convención para futuras imágenes
Usaremos nombres numéricos para que puedas sustituirlas fácilmente:
- `1.png`: logo principal
- `2.png`: imagen siguiente que incorporemos
- `3.png`: imagen siguiente
- etc.

Cuando añadamos una imagen a la web, te indicaré el número que debe tener el archivo.
