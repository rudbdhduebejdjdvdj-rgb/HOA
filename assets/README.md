# Imágenes de NightClaw AI

Guarda aquí las imágenes que use la web.

## Logo principal
- Nombre exacto: `logo.png`
- Ruta: `assets/logo.png`
- Tamaño recomendado: **512 × 512 píxeles**.
- Formato recomendado: PNG con fondo transparente.
- Usa un logo cuadrado; la web lo mostrará en un espacio de 46 × 46 píxeles y mantendrá la proporción.

Para cambiarlo, sube tu imagen a esta carpeta con el nombre exacto `logo.png` (reemplazando el archivo si ya existe).

## Otras imágenes
Puedes guardar aquí imágenes adicionales y referenciarlas desde `index.html`, por ejemplo `assets/fondo.png` o `assets/icono-biblioteca.svg`.
